How BOUNDARY works

  1. 1Classifydeterministic proposal
  2. 2Guardpermission check
  3. 3Journalsimulated record
  4. 4Verifyindependent re-check
  • Deterministic routing — exact matches and held cases resolve with zero model calls.
  • Selective advisory inference — a model is consulted only for genuinely ambiguous cases, and its output is advisory (execution_authority = NONE).
  • Independent verification — every journal record is re-checked against the source case before it is trusted.
